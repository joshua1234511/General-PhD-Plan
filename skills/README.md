# Skills

An AI assistant skill for research students. It is plain Markdown instructions plus
templates — nothing to compile, no account needed, no network access required.

| Skill | For | Start here |
|---|---|---|
| **[research-paper-manager/](research-paper-manager/)** | One paper, from idea to submission to reviewer response. Literature scan, citation audit, pre-submission peer review, venue prep, rebuttal. | [how-to](research-paper-manager-how-to.md) |

It ships four things:

- `<skill>/` — the skill folder itself
- `<skill>.zip` — the same folder, zipped, for handing to someone
- `<skill>-how-to.md` — what it does and how to use it, for you
- an install guide — **hand this to an AI assistant and it does the install for you**
  ([research-paper-manager-install.md](research-paper-manager-install.md))

Every document is also provided as `.html`, `.docx` and `.pdf` if you would rather read or
print it that way.

## Quickest path

1. Unzip `research-paper-manager.zip`.
2. Copy the folder into `~/.claude/skills/`.
3. Start a new Claude Code session and ask for what you want in plain English.

Not using Claude Code? The install guide covers Cursor, GitHub Copilot and ChatGPT too.
