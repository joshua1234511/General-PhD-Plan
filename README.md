# PhD Coursework Plan — Term IV (Shared Study Resource)

A **general, shareable** study pack for the Year-1 / Term IV coursework of the
**PhD & PhD-WP programme at IIM Sambalpur (AY 2026–27)**. It collects the four
core methods courses, their schedules, assessments, class-ready reading briefings,
and reusable trackers — with **no personal content** — so classmates can adopt it
as a common scaffold.

> This is a community resource, not an official document. Where it digests the
> programme manual, **the official IIM Sambalpur PhD & PhD-WP Manual 2026 always
> wins** — verify any hard gate (credits, grades, milestone timelines, publication
> rules) against the latest official manual and annexures.

## How to use this pack

1. Read [`program-requirements.md`](program-requirements.md) first — it carries the
   hard rules the whole programme runs on.
2. Open the [coursework dashboard](coursework/dashboard.md) for the four courses,
   assessments, and the full class schedule on one page.
3. For each course, the folder holds: a **README** (syllabus, instructor,
   assessments, readings), **briefing notes** (class-ready abstracts + questions to
   ask), a blank **notes.md** to capture lectures, and a **project-tracker.md** that
   runs each deliverable through a submit → feedback → rework pipeline.
4. Copy [`progress-template.md`](progress-template.md) to keep your own running log.

## Conventions used throughout

**Status:** ⬜ not started · 🟡 in progress · ✅ done · ⛔ blocked

**Deliverable pipeline:**
```
⬜ Not started → ✍️ Drafting → 📤 Submitted → 💬 Feedback → 🔁 Reworking → ✅ Done
```

## Per-course folder layout

```
<course>/
  README.md            — syllabus, instructor, assessments, key readings
  reading-materials/    — briefing notes; drop papers, slides, chapters here
  notes.md              — running lecture notes & takeaways (blank template)
  project-tracker.md    — deliverable status (submit → feedback → rework)
```

> Adapt freely. Add your own readings, assignments, and notes — the structure is
> meant to be a starting scaffold, not a straightjacket.
