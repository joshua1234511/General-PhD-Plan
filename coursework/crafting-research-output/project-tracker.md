## How to run each reading

For every assigned article, add a row above and a section below, then run it through
the pipeline:

1. **Draft** a Word doc — summary + reflection (what you like, relevance, limitations,
   positives) + a discussion question to lead with.
2. **Present** in class (from the Word doc, no PPT); be ready to lead discussion.
3. **Capture** faculty/peer feedback → rework if needed → mark ✅ Done.

### Example section format
```
## <n> · <Reading title> (<Author, Year>)
- [ ] Summary + reflection drafted (Word)
- [ ] Presented in class
- [ ] Feedback captured → reworked if needed
**Cycle log:**
- [YYYY-MM-DD] <what moved>
```
