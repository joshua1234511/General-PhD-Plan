## Folder convention (per subject)

```
<subject>/
  README.md            — syllabus, instructor, assessments, key readings
  reading-materials/    — briefing notes; drop papers, slides, chapters here
  notes.md              — running lecture notes & takeaways (blank template)
  project-tracker.md    — deliverable status (submit → feedback → rework)
```

## How to use these folders

- **README** — the syllabus, instructor, assessment breakdown, and reading list.
- **reading-materials/briefing-notes.md** — class-ready abstracts + "questions to
  ask" for the course readings, so you can skim and be ready to contribute.
- **notes.md** — capture each session's concepts and takeaways (a blank template is
  provided; newest session at the top).
- **project-tracker.md** — run each deliverable through the pipeline
  `⬜ Not started → ✍️ Drafting → 📤 Submitted → 💬 Feedback → 🔁 Reworking → ✅ Done`.
